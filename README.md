# The Comedy Factory - Website Redesign Concept 

A modern, responsive frontend redesign concept for **The Comedy Factory**, built to elevate their digital presence and optimize how fans discover and book comedy shows. 

This project was built from scratch as a concept pitch to demonstrate a cleaner, more engaging user experience compared to the current live site.

---

##  Main Focus: The "Shows" Section Revamp
The core objective of this project was to completely reimagine the **Upcoming Shows** experience. On an entertainment website, the show listing is the most critical conversion point. 

### Key Improvements Made:
*   High-Visibility Event Cards: Redesigned the show listings with clear, bold typography for dates, timings, and venues so users can scan information instantly.
*   Streamlined Booking Flow: Placed intuitive, prominent Call-to-Action (CTA) buttons for ticket bookings to minimize friction and increase conversions.
*   Visual Hierarchy: Used high-contrast design and cleaner alignment to make artist lineups and show titles stand out, matching the high energy of a live comedy brand.
*   Mobile-Optimized Grid: Ensured the shows section scales beautifully on smartphones, where the majority of users browse for weekend plans.
